# Интеграция персонажей и загруженных ассетов

## Реализовано

- Рабочая модель человека взята из `Universal Animation Library 1 Standard` без root motion. Движением по миру продолжает управлять `CharacterBody3D`.
- Runtime-копия модели: `res://gameplay/humans/assets/ual1_human.glb`.
- Дополнительная библиотека UAL2 сохранена как `res://gameplay/humans/assets/ual2_human.glb` для дальнейшего расширения набора действий.
- UAL имеет лицензию CC0; оригинальные файлы лицензии остаются в загруженном пакете.
- Визуальная модель развёрнута на 180 градусов относительно корня человека. Направление восприятия, навигация и физика при этом не меняются.
- `HumanAnimationComponent` независимо от FSM выбирает `Idle`, `Walk`, `Jog_Fwd`, `Sprint` и `Death01`.
- Для охранника подключены `Pistol_Idle` и `Pistol_Shoot`. Событие настоящего выстрела приходит из `RangedCombatComponent`.
- Пистолет экспортирован из `You see Ivan Pack/pistol.blend` в `res://gameplay/humans/assets/guard_pistol.glb`.
- `HumanWeaponComponent` создаёт оружие только для роли `Guard` и крепит его к кости `hand_r` через `BoneAttachment3D`.
- Примитивная капсула-модель скрыта, но коллизия, здоровье, восприятие и узловая FSM сохранены отдельными компонентами.

## Исходные библиотеки

- `res://assets/animations/Universal Animation Library/` — исходный пакет анимаций.
- `res://assets/models/Characters_psx_1.1/` — 227 FBX-моделей персонажей и набор текстур.
- `res://assets/models/You see Ivan/` — исходники оружия.
- Остальные архивы в `res://assets/models/` содержат вентиляцию, шахту, канализацию, офис, бочки, ящики и другие пропсы.

Сырые крупные библиотеки помечены `.gdignore`. В рабочие каталоги копируются только выбранные и подготовленные ресурсы, чтобы Godot не импортировал сотни вариантов при каждом сканировании.

## PSX-персонажи — следующий этап

Ригованные PSX-модели используют Mixamo-подобную иерархию с корнем `mixamorig:Hips`. UAL использует Unreal-совместимый скелет из 65 костей (`root`, `pelvis`, `spine_01`, `hand_r` и другие). Поэтому анимации нельзя просто назначить PSX-модели.

Для переноса требуется:

1. Выбрать конкретные модели работника и охранника.
2. Импортировать их выборочно, вместе с соответствующими текстурами.
3. Создать `BoneMap` на основе `SkeletonProfileHumanoid` для Mixamo-скелета и UAL.
4. Проверить rest pose, масштаб, направление вперёд и деформации кистей.
5. После визуальной проверки заменить только содержимое `VisualRoot`; игровая логика и FSM не потребуют переделки.

## Пока не интегрировано

- PSX-модели не используются в канонической сцене человека до завершения ретаргета.
- Пропсы и наборы окружения ещё не распределены по игровым сценам и TrenchBroom point-классам.
- Положение и поворот оружия на кисти заданы как редактируемые параметры компонента и могут потребовать визуальной доводки в редакторе.
